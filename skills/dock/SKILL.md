# /dock - End Session

Capture session context for the next session. Focus on what's in your head that Beads can't store.

---

## Procedure

### Step 1: Gather Git State

```bash
git branch --show-current
git status --short
git log -1 --oneline
```

### Step 2: Write Handover

Write `.space-agents/comms/handover.md` with session context.

**IMPORTANT:** Do NOT include Beads data (tree, ready tasks, stats). Launch queries Beads directly. Focus on narrative context only.

```markdown
# Handover

**Date:** YYYY-MM-DD HH:MM
**Branch:** {branch}
**Git:** {clean/uncommitted changes}

---

## What Happened This Session

[Narrative of what was worked on. Be specific - file names, function names, what changed and why. This is the story of the session.]

---

## Decisions Made

[Any architectural decisions, trade-offs chosen, or "we decided to X because Y" moments. These are easily lost between sessions.]

---

## Gotchas & Learnings

[Things that surprised you, bugs encountered, "watch out for X", anything the next session should know to avoid wasting time.]

---

## In-Progress Work

[If you stopped mid-task, what state is it in? What was the next step? What files were you looking at?]

---

## Recommended Next Action

[One clear thing to do next. Not a list - the single most important next step.]

---

*Generated by /dock*
```

**Guidelines:**
- Be specific, not vague ("updated the auth flow" → "added JWT refresh logic to auth/tokens.ts:45")
- Include file paths and line numbers where relevant
- Capture reasoning, not just actions
- If nothing notable happened, say so briefly

### Step 3: Append to CAPCOM

Append short summary to `.space-agents/comms/capcom.md`:

```markdown
## [YYYY-MM-DD HH:MM] Session End

**Summary:** [One sentence describing the session]
**Branch:** {branch} | **Git:** {clean/dirty}

Tasks completed: {list or "none"}
Features completed: {list or "none"}
Bugs fixed: {list or "none"}

See handover.md for full context.

---
```

### Step 4: Sync Beads

```bash
bd sync
```
